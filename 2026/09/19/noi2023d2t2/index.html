题目链接： [NOI2023] 字符串 。

题目描述：

小 Y 了解到关于字符串的如下定义:

  • 给定一个长度为 nnn 的字符串 s[1:n]s[1: n]s[1:n]，我们定义其子串 s[l:r]s[l: r]s[l:r]（1≤l≤r≤n1 \leq l \leq r \leq n1≤l≤r≤n）为选择 s[l],s[l+1],…,s[r]s[l], s[l+1], \dots, s[r]s[l],s[l+1],…,s[r], 将其顺次拼接得到的新字符串。
  • 给定一个长度为 nnn 的字符串 s[1:n]s[1: n]s[1:n]，我们定义其翻转后的结果 R(s)R(s)R(s) 为将 s[n],s[n−1],…,s[1]s[n], s[n-1], \dots, s[1]s[n],s[n−1],…,s[1] 顺次拼接，也就是将字符串反序拼接得到的字符串。
  • 给定两个长度均为 nnn 的字符串 a[1:n],b[1:n]a[1: n], b[1: n]a[1:n],b[1:n]，我们定义 aaa 的字典序小于 bbb 当且仅当存在 1≤i≤n1 \leq i \leq n1≤i≤n，使得对于任意 1≤j<i1 \leq j < i1≤j<i，a[j]=b[j]a[j] = b[j]a[j]=b[j]，且 a[i]<b[i]a[i] < b[i]a[i]<b[i]。

在了解了上述定义后，小 Y 想到了这样的问题:

给定一个长度为 nnn 的字符串 s[1:n]s[1: n]s[1:n]。有 qqq 次询问，每次询问给定两个参数 i,ri, ri,r。你需要求出有多少 lll，满足如下条件:

  • 1≤l≤r1 \leq l \leq r1≤l≤r。
  • s[i:i+l−1]s[i: i+l-1]s[i:i+l−1] 字典序小于 R(s[i+l:i+2l−1])R(s[i+l: i+2l-1])R(s[i+l:i+2l−1])。

小 Y 想求助你帮忙解决这一问题。

n,q≤105n,q\le 10^5n,q≤105 。

暴力可以做到 O(qn2)O(qn^2)O(qn2) ，使用 SA 或哈希优化后可以做到 O(qn)O(qn)O(qn) 或 O(qnlog⁡n)O(qn\log n)O(qnlogn) ，能拿到 36%36\%36% 的分数。

此时我们发现我们没有什么好办法可以直接刻画限制，于是考虑：

  • 加紧限制，然后统计漏掉的。
  • 放松限制，然后扣掉不合法的。

在这里定义 SiS_iSi​ 表示从 iii 开始的后缀， PiP_iPi​ 表示从 iii 开始的前缀。

不妨把 s[i:i+l−1]<R(s[i+l:i+2l−1])s[i:i+l-1]<R(s[i+l:i+2l-1])s[i:i+l−1]<R(s[i+l:i+2l−1]) 改为 Si<Pi+2l−1S_i<P_{i+2l-1}Si​<Pi+2l−1​ ，这样做容易发现是放松了限制，于是我们要减去不合法的。

Part I. 放松的限制

考虑将 sss 和 sRs^RsR 拼接，这样就可以把 PPP 转化为一个后缀。这里为了好处理细节，将 s+c+sR+ds+c+s^R+ds+c+sR+d 进行拼接，其中 c,dc,dc,d 为两个不同的字符。

然后构建 SA ，此时限制直接变为：

  • rki<rkjrk_i<rk_jrki​<rkj​ 。
  • j mod 2≠i mod 2j\bmod 2\ne i\bmod 2jmod2=imod2 。
  • i+1≤j≤i+2r−1i+1\le j\le i+2r-1i+1≤j≤i+2r−1 。

这是一个经典的二维数点问题，用奇数偶数两个 BIT 维护即可。

Part II. 不合法情况

观察一下，我们发现，如果 Si<Pi+2l−1S_i<P_{i+2l-1}Si​<Pi+2l−1​ 不满足，必然意味着 s[i:i+l−1]=R(s[i+l:i+2l−1])s[i:i+l-1]=R(s[i+l:i+2l-1])s[i:i+l−1]=R(s[i+l:i+2l−1]) ，即， s[i:i+2l−1]s[i:i+2l-1]s[i:i+2l−1] 是一个回文串！

在这种情况下，考虑一个回文中心 i,i+1i,i+1i,i+1 ，设她的最大回文半径为 RiR_iRi​ ，考虑 0≤l≤Ri0\le l \le R_i0≤l≤Ri​ ，则 Si−R1≥Pi+Ri−1⇔Si+Ri≥Pi−Ri−1S_{i-R_1}\ge P_{i+R_i-1}\Leftrightarrow S_{i+R_i}\ge P_{i-R_i-1}Si−R1​​≥Pi+Ri​−1​⇔Si+Ri​​≥Pi−Ri​−1​ 。

又因为回文串的最大半径为 RiR_iRi​ ，也就是说， Si+RiS_{i+R_i}Si+Ri​​ 和 Pi−Ri−1P_{i-R_i-1}Pi−Ri​−1​ 的前几位必然一样，直到 RiR_iRi​ 为之后才能开始比较。又因为 RiR_iRi​ 是最大的，所以必然有 si+Ri≠si−Ri−1s_{i+R_i}\ne s_{i-R_i-1}si+Ri​​=si−Ri​−1​ 。所以，只要满足 si+Ri≠si−Ri−1s_{i+R_i}\ne s_{i-R_i-1}si+Ri​​=si−Ri​−1​ ，就必然有任意的 0≤l≤Ri0\le l\le R_i0≤l≤Ri​ 都满足 Si−Ri≥Pi+1+RiS_{i-R_i}\ge P_{i+1+R_i}Si−Ri​​≥Pi+1+Ri​​ 。
