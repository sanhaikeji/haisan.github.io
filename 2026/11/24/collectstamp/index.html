主要难在性质，后面的部分就很简单了。

::::info[题面]

P11987 [JOIST 2025] 集邮比赛 4 / Collecting Stamps 4

题目背景

本题测试点极大，评测时可能需要等待较长时间加载测试点。

题目描述

在湖泊周围，有 2N2N2N 个均匀分布的地点，按顺时针方向编号为 111 到 2N2N2N。此外，还有 2N2N2N 条单向道路连接相邻的地点。道路 iii（1≤i≤2N−11 \leq i \leq 2N - 11≤i≤2N−1）从地点 iii 通往地点 i+1i+1i+1，而道路 2N2N2N 从地点 2N2N2N 通往地点 111。每条道路的中点处设有一个印章台。

共有 NNN 种颜色的印章，编号为 111 到 NNN。在道路 iii（1≤i≤2N1 \leq i \leq 2N1≤i≤2N）的印章台上可以获得的印章颜色为 AiA_iAi​。对于每种颜色 jjj（1≤j≤N1 \leq j \leq N1≤j≤N），恰好有 222 个印章台提供该颜色的印章。

JOI 君携带了多张集章卡参加比赛。每张集章卡有左、右两个空格，可以加盖印章。每个空格最多加盖一枚印章。初始时，所有集章卡均为空白。

JOI 君参加集章拉力赛的流程如下：

  1. 首先，选择 2N2N2N 个地点中的一个作为起点，并移动至该地点。若选择地点 iii（1≤i≤2N1 \leq i \leq 2N1≤i≤2N），则需要支付参与费用 CiC_iCi​。
  2. 接着，他可以指令主办方交换相邻的印章台。具体来说，可以交换道路 2N2N2N 和 111 的印章台，或者交换道路 i−1i-1i−1 和 iii 的印章台（2≤i≤2N2 \leq i \leq 2N2≤i≤2N）。每次交换需花费 XXX，JOI 君可以执行任意多次的交换（包括零次）。交换操作会在指令下达后立即执行。但为了防止作弊，不允许交换跨越 JOI 君所选起点的印章台。即：
    • 若起点为地点 111，则禁止交换道路 2N2N2N 和 111 的印章台。
    • 若起点为地点 iii（2≤i≤2N2 \leq i \leq 2N2≤i≤2N），则禁止交换道路 i−1i-1i−1 和 iii 的印章台。
  3. 此后，JOI 君从所选起点出发，按顺时针方向依次访问 2N2N2N 个印章台。访问印章台时，他可以任意次地在该台为集章卡盖章。同一张卡可以在同一台同时加盖左、右两格。但每张集章卡必须先在左空格盖章，之后才能在右空格盖章，即若某卡的左空格未盖章，则不能在该卡的右空格盖章。

JOI 君想要收集尽可能多不同类型的已盖章卡。定义盖章卡 (a,b)(a, b)(a,b) 为左空格为颜色 aaa、右空格为颜色 bbb 的集章卡。

当且仅当 a1=a2a_1 = a_2a1​=a2​ 且 b1=b2b_1 = b_2b1​=b2​ 时，盖章卡 (a1,b1)(a_1, b_1)(a1​,b1​) 和 (a2,b2)(a_2, b_2)(a2​,b2​) 被视为同一种类型。

由于共有 NNN 种颜色，因此总共有 N2N^2N2 种可能的盖章卡类型。

有 QQQ 个查询。第 qqq 个查询（1≤q≤Q1 \leq q \leq Q1≤q≤Q）的内容如下：

  • 若要使得 JOI 君在拉力赛结束时收集到至少 KqK_qKq​ 种类型的盖章卡，所需的最小总成本是多少？

可以证明，在给定的约束条件下，JOI 君总能通过足够大的成本收集到至少 KqK_qKq​ 种类型的盖章卡。

说明/提示

样例 111 解释

考虑 JOI 君选择地点 222 作为起点，并指令交换道路 333 和 444 上印章台的情况：

  • JOI 君支付的总成本为 C2+X×1=3C_2 + X \times 1 = 3C2​+X×1=3。
  • JOI 君按道路 2→3→4→5→6→12\to 3\to 4\to 5\to 6\to 12→3→4→5→6→1 的顺序访问印章台，各台可获得的印章颜色依次为 2,3,2,1,3,12,3,2,1,3,12,3,2,1,3,1。
  • JOI 君可收集的双空格盖章卡类型数为 888 种。
    ◦ 例如，要获得左格为颜色 333、右格为颜色 111 的盖章卡，JOI 君可在道路 333 的台加盖左格，在道路 111 的台加盖右格。
    ◦ 但需注意，无法获得左格为颜色 111、右格为颜色 222 的盖章卡。

由于无法以 222 或更低的成本获得 888 种及以上类型的盖章卡，输出的第一行应为 333。

此外，若 JOI 君选择地点 333 作为起点且不进行任何印章台交换，他可获得 999 种类型的盖章卡：

  • 此时 JOI 君支付的总成本为 C3+X×0=4C_3 + X \times 0 = 4C3​+X×0=4。由于无法以 333 或更低的成本获得 999 种及以上类型的盖章卡，输出的第二行应为 444。

该样例满足子任务 1,4,61,4,61,4,6 的限制。

  2. 交换道路 222 和 333 的印章台；

首先将 2n2n2n 个数字复制一份拼接在后面，那么所有的起点引导的路径相当于截取一个长度为 2n2n2n 的区间。

先考虑如何在无修改、固定起点的情况下求出不同类型的印章卡片数量。这个比较简单：设 pi,0/1p_{i,0/1}pi,0/1​ 表示印章 iii 第 0/10/10/1 次出现的位置，那么 (a,b)(a,b)(a,b) 无法被获得当且仅当 pa,0>pb,1p_{a,0}>p_{b,1}pa,0​>pb,1​。如果把每一个印章第一次出现看成数字 000，第二次出现看成 111，那么无法出现的印章卡片的数量为序列的逆序对数。

接下来加入交换操作。我们就要考虑如何交换能使得 010101 序列的逆序对数最小化。这个就很明显了：只要逆序对数不为 000，就必定存在至少一个逆序对；因此至少存在一个 111 后面紧跟着 000，那么我们交换他们即可。所以我们就可以得出结论：

对于任意一个局面，只要存在印章卡片不能被收集，则一次交换操作一定能使得可收集的印章卡片数量 +1+1+1。

事实上从逆序对的角度看，这一切都变得十分显然了。证明也不需要长篇大论的写了。

::::

有了这个性质之后就简单了。我们先求出不交换时以每一个点为起点时的印章卡片数量，这个可以简单的使用两个树状数组维护。然后设 fif_ifi​ 表示拥有 ≥i\ge i≥i 个印章卡片的最小花费。我们先将所有起点对应的数值加入到 fff 中，然后对每一个 iii 取一个后缀 min⁡\minmin（这是为了保证，我如果能以更小的代价获得 ≥i+1\ge i+1≥i+1 个卡片，就一定能以相同的代价获得 ≥i\ge i≥i 个卡片）。然后再对于每一个 iii，转移 fi=min⁡(fi,fi−1+X)f_i=\min(f_i,f_{i-1}+X)fi​=min(fi​,fi−1​+X)。实际实现的时候我们当然不能枚举 O(n2)\mathcal{O}(n^2)O(n2) 个值。但是这个转移实在是太简单了，以至于直接离散化后依然能 O(1)\mathcal{O}(1)O(1) 转移。

这样就没了。
