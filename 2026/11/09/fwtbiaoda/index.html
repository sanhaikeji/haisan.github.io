P7324 [WC2021] 表达式求值

题目描述

定义二元操作符 <：对于两个长度都为 nnn 的数组 A,BA, BA,B（下标从 111 到 nnn），AAA<BBB 的结果也是一个长度为 nnn 的数组，记为 CCC。则有 C[i]=min⁡(A[i],B[i])C[i] = \min(A[i], B[i])C[i]=min(A[i],B[i])（1≤i≤n1 \le i \le n1≤i≤n）。

定义二元操作符 >：对于两个长度都为 nnn 的数组 A,BA, BA,B（下标从 111 到 nnn），AAA>BBB 的结果也是一个长度为 nnn 的数组，记为 CCC。则有 C[i]=max⁡(A[i],B[i])C[i] = \max(A[i], B[i])C[i]=max(A[i],B[i])（1≤i≤n1 \le i \le n1≤i≤n）。

现在有 mmm（1≤m≤101 \le m \le 101≤m≤10）个长度均为 nnn 的整数数组 A0,A1,…,Am−1A_0, A_1, \ldots , A_{m-1}A0​,A1​,…,Am−1​。给定一个待计算的表达式 EEE，其满足 EEE 中出现的每个操作数都是 A0,A1,…,Am−1A_0, A_1, \ldots , A_{m-1}A0​,A1​,…,Am−1​ 其中之一，且 EEE 中只包含 < 和 > 两种操作符（< 和 > 的运算优先级相同），因此该表达式的结果值也将是一个长度为 nnn 的数组。

特殊地，表达式 EEE 中还可能出现操作符 ?，它表示该运算符可能是 < 也可能是 >。因此若表达式中有 ttt 个 ?，则该表达式可生成 2t2^t2t 个可求确定值的表达式，从而可以得到 2t2^t2t 个结果值，你的任务就是求出这 2t2^t2t 个结果值（每个结果都是一个数组）中所有的元素的和。你只需要给出所有元素之和对 109+7{10}^9 + 7109+7 取模后的值。

输入格式

第一行两个整数 n,mn, mn,m，分别表示数组长度与数组个数。

第 2∼m+12 \sim m + 12∼m+1 行每行 nnn 个用空格分隔的整数，第 iii 行第 jjj 个元素代表 Ai−2[j]A_{i-2}[j]Ai−2​[j]（2≤i≤m+12 \le i \le m + 12≤i≤m+1，1≤j≤n1 \le j \le n1≤j≤n）。

最后一行一个字符串 SSS，表示表达式 EEE。SSS 中只包含字符 0 到 9、(、)、<、>、?，数字字符表示操作数的下标，例如字符 2 表示表达式中的操作数为 A2A_2A2​。

输出格式

仅一行一个整数，表示所有 2t2^t2t 个表达式的结果，它们的元素之和模 109+7{10}^9 + 7109+7 的值。

显然建立表达式树然后在表达式树上处理。

然后注意到每一个序列的 nnn 个数实际上互相独立，因此可以分开计算。

::::info[无用 O(nm∣S∣)\mathcal{O}(nm|S|)O(nm∣S∣) 做法]

不妨对于表达式树上每一个节点记录其所有可能的值和其方案数。

合并两个节点是只需要双指针线性扫描即可。

然后就没了，由于错误的启发式合并分析认为复杂度 O(m∣S∣log⁡(nm))\mathcal{O}(m|S|\log(nm))O(m∣S∣log(nm))，但是实际上 O(nm∣S∣)\mathcal{O}(nm|S|)O(nm∣S∣)，只有 707070 分。

::::

这里又有 min⁡\minmin 又有 max⁡\maxmax，因此考虑 min-max\text{min-max}min-max 容斥。即 min⁡(a,b)=a+b−max⁡(a,b)\min(a,b)=a+b-\max(a,b)min(a,b)=a+b−max(a,b)。

于是，所有的数就会变为若干个 max⁡\maxmax 加加减减：具体的，例如 max⁡(min⁡(a,b),c)=min⁡(max⁡(a,c),max⁡(b,c))=max⁡(a,c)+max⁡(b,c)−max⁡(a,b,c)\max(\min(a,b),c)=\min(\max(a,c),\max(b,c))=\max(a,c)+\max(b,c)-\max(a,b,c)max(min(a,b),c)=min(max(a,c),max(b,c))=max(a,c)+max(b,c)−max(a,b,c)。

这样的若干的不同的集合的数量是 2m2^m2m，而 mmm 较小，因此考虑状压。

令 fx,Sf_{x,S}fx,S​ 表示节点 xxx 的子树内部，构成 max⁡{S}\max\{S\}max{S} 的方案数。

  • ???：
    • fu,Sfv,T→fx,Sf_{u,S}f_{v,T}\to f_{x,S}fu,S​fv,T​→fx,S​。
    • fu,Sfv,T→fx,Tf_{u,S}f_{v,T}\to f_{x,T}fu,S​fv,T​→fx,T​。
  • <<<：
    • fu,Sfv,T→fx,Sf_{u,S}f_{v,T}\to f_{x,S}fu,S​fv,T​→fx,S​。
    • fu,Sfv,T→fx,Tf_{u,S}f_{v,T}\to f_{x,T}fu,S​fv,T​→fx,T​。
    • −fu,Sfv,T→fx,S∪T-f_{u,S}f_{v,T}\to f_{x,S\cup T}−fu,S​fv,T​→fx,S∪T​。

直接转移时 O(4m(∣S∣+n))\mathcal{O}(4^m(|S|+n))O(4m(∣S∣+n)) 的，不过可以 FWT 优化为 O(2m(∣S∣+n))\mathcal{O}(2^m(|S|+n))O(2m(∣S∣+n))。
