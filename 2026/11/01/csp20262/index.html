P17832 [CSP-S 2026] 地铁 / subway（民间数据）

题目描述

B 市共有 mmm 个地铁站，编号为 111 到 mmm。每个地铁站都有一个站厅，地铁口与站厅之间有一条通道，往返耗时相同。从第 vvv（1≤v≤m1 \le v \le m1≤v≤m）个地铁站的地铁口走到站厅需要 wvw_vwv​ 的时间。

B 市共有 nnn 条地铁线路，编号为 111 到 nnn，其中第 iii（1≤i≤n1 \le i \le n1≤i≤n）条线路经过 kik_iki​ 个地铁站，编号依次为 ai,1,ai,2,…,ai,kia_{i,1},a_{i,2},\ldots,a_{i,k_i}ai,1​,ai,2​,…,ai,ki​​。在第 ai,ja_{i,j}ai,j​（1≤j≤ki1 \le j \le k_i1≤j≤ki​）个地铁站处，从站厅走到第 iii 条线路的站台需要 ti,jt_{i,j}ti,j​ 的时间，往返耗时相同。同一条线路不会重复经过同一个地铁站，即 ai,1,ai,2,…,ai,kia_{i,1},a_{i,2},\ldots,a_{i,k_i}ai,1​,ai,2​,…,ai,ki​​ 两两不同。

由于空间有限，每个地铁站最多有 ddd 条线路经过。此外，B 市的地铁网络是连通的，即任意两个地铁站都可以通过若干条线路互相到达。

小 R 有 qqq 个出行计划。对于第 rrr（1≤r≤q1 \le r \le q1≤r≤q）个出行计划，小 R 将从第 xrx_rxr​ 个地铁站的地铁口出发，乘坐地铁到达第 yry_ryr​ 个地铁站的地铁口，途中可能进行若干次站内换乘。每次站内换乘都需要从一条线路的站台先走到站厅，再从站厅走到另一条线路的站台。每个出行计划的总步行时间为进出站和换乘的步行时间之和。小 R 希望每个出行计划的总步行时间都尽可能少。

你需要帮助小 R 求出，每个出行计划的最小总步行时间。

输入格式

从文件 subway.in 中读入数据。

输入的第一行包含五个非负整数 c,n,m,d,qc,n,m,d,qc,n,m,d,q，分别表示测试点编号、地铁线路数、地铁站数、每个地铁站最多被几条线路经过，以及出行计划数。特别地，若 c=0c=0c=0，则该测试点为样例。

输入的第二行包含 mmm 个正整数 w1,w2,…,wmw_1,w_2,\ldots,w_mw1​,w2​,…,wm​，依次表示从每个地铁站的地铁口走到站厅需要的时间。

输入的第 i+2i+2i+2（1≤i≤n1 \le i \le n1≤i≤n）行包含 1+2ki1+2k_i1+2ki​ 个正整数，其中第一个正整数为 kik_iki​，表示第 iii 条线路经过的地铁站数；接下来 2ki2k_i2ki​ 个正整数为 ai,1,ti,1,ai,2,ti,2,…,ai,ki,ti,kia_{i,1},t_{i,1},a_{i,2},t_{i,2},\ldots,a_{i,k_i},t_{i,k_i}ai,1​,ti,1​,ai,2​,ti,2​,…,ai,ki​​,ti,ki​​，其中 ai,ja_{i,j}ai,j​ 表示第 iii 条线路经过的第 jjj 个地铁站，ti,jt_{i,j}ti,j​ 表示从该地铁站的站厅走到第 iii 条线路的站台需要的时间。

输入的第 r+n+2r+n+2r+n+2（1≤r≤q1 \le r \le q1≤r≤q）行包含两个正整数 xr,yrx_r,y_rxr​,yr​，分别表示第 rrr 个出行计划的起点和终点所在的地铁站编号。

输出格式

输出到文件 subway.out 中。

输出 qqq 行，其中第 rrr（1≤r≤q1 \le r \le q1≤r≤q）行包含一个非负整数，表示第 rrr 个出行计划的最小总步行时间。
