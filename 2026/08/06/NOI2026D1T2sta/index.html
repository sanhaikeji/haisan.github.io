[NOI 2026] 传送 实现细节

上篇题解是口胡的，写完代码后感觉有点细节。

代码结构：

Part I 交互函数

vector<pli>teleport(int c,int n,int m,V ur,V vr,V xr,V yr);

DFT 已经提供好了所有函数，模拟就行。

Part II 有理数结构体

ll gcd(ll a,ll b);

struct Q{};

可以直接模拟分数四则运算。不过要注意，为了保证性能，可以在所有运算结束后最后约分。

Part III dfn-lca

int Min(int x,int y);

void dfs(int x,int fa);

int lca(int x,int y);

int dist(int x,int y);

经典 dfn-lca ，可以利用 RMQ 做到 O(nlog⁡n)∼O(1)\mathcal{O}(n\log n)\sim\mathcal{O}(1)O(nlogn)∼O(1) 或 O(n)∼O(1)\mathcal{O}(n)\sim\mathcal{O}(1)O(n)∼O(1) 。

Part IV 找重心

getrt(int x,int fa);

板子。

Part V 点分治

void dfs2(int x,int fa,int aim,int c[],ll res[],int &mx);

void solve(int x);

我们的目标是处理树上 kkk 邻域数点。

回顾一下过程，我们需要处理出每一个分治重心 xxx 的分治子树内所有点到 xxx 的距离，以及 xxx 的分治子树内到 xxx 分治父亲 fff 的距离，以及距离和。

处理完后，我们需要把这些信息放在桶里并统计前缀和。

以上与点分树 / 震波是一致的。

但是，考虑到每个分治重心 xxx 的分治子树内距离最远的点到 xxx 距离互不相同。

考虑到这题 n≤5×105n\le5\times10^5n≤5×105 ，所以我们不能向震波一样使用常数巨大的 vector ，而应该使用类似于长链剖分的指针。

具体的，定义 c[] 和 c2[] 分别代表距离 xxx 不超过 kkk 的点个数， res[] 和 res2[] 分别代表距离 xxx 不超过 kkk 的点距离和。

然后，定义 addr[] 和 ed[] 代表 xxx 的桶在 c[] 和 res[] 中的范围，定义 addr2[] 和 ed2[] 代表 xxx 的桶在 c2[] 和 res2[] 中的范围。

这样就可以成功规避 vector 。

其他的和震波别无二致。

Part VI query(x,k)

query(int x,int k);

这个函数和震波里的那个没什么区别。

就是经典树上 kkk 邻域数点的查询。

不过要注意边界问题。

Part VII cost(x,k)

cost(int x,int k);

推一下公式即可。

不妨定义 SSS 为期望， yyy 为距离 xxx 不超过 kkk 的点个数， YYY 为距离 xxx 不超过 kkk 的点到 xxx 的距离和。

那么就有 S=1+n−ynS+ynYS=1+\frac{n-y}{n}S+\frac{y}{n}YS=1+nn−y​S+ny​Y 。

解得 S=n+YyS=\frac{n+Y}{y}S=yn+Y​ 。

Part VIII get_tele_ans(x,y)

get_tele_ans(int x,int y);

设 E[p]E[p]E[p] 为节点 ppp 作为终点时，选择随机传送的点的最低期望。

那么直接返回 min⁡{d(x,y),E[y]}\min\{d(x,y),E[y]\}min{d(x,y),E[y]} 就行。

Part IX 初始化点分树

build(V &ur,V &vr);

首先，我们要根据 ur 和 vr 建边。

然后，我们要调用 dfs 初始化 lca 。

接着，我们要用 solve 建立点分树。

之后，我们要初始化 dis[i][p] 表示 iii 的点分树上的 ppp 级父亲和 iii 的距离。

最后，我们要用 cost 二分最优的 E[] 。

然后就 O(nlog⁡2n)\mathcal{O}(n\log^2n)O(nlog2n) 通过此题。
