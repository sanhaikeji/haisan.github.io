[ICPC 2016 NAIPC] Jewel Thief

逆天背包。

题目链接： [ICPC 2016 NAIPC] Jewel Thief 。

题目描述：

给 nnn 个物品，每个物品有价值 viv_ivi​ 和重量 wiw_iwi​ ，你需要对于每一个 1≤i≤k1\le i \le k1≤i≤k ，求出大小为 iii 的背包的最大价值。

  • 1≤n≤1061\le n\le 10^61≤n≤106 。
  • 1≤k≤1051\le k \le 10^51≤k≤105 。
  • 1≤vi≤1091\le v_i\le 10^91≤vi​≤109 。
  • 1≤wi≤3001\le w_i\le 3001≤wi​≤300 。

一个普通的背包 DP ，但是直接背包复杂度 O(nk)\mathcal{O}(nk)O(nk) ，过不了。

考虑从 wi≤300w_i\le 300wi​≤300 入手。不妨把所有的相同重量的物品经行分组，同组内的按权值从大到小排序后累加的前缀和数组为 ai,ja_{i,j}ai,j​ ，共有 szisz_iszi​ 物品。

那么写出 DP 式子（不妨设这一轮 DP 结果 fif_ifi​ ，上一轮 gig_igi​ ，这是第 ttt 轮）。

fi=max⁡0≤j≤szt{gi−j×t+at,j}f_i=\max_{0\le j\le sz_t}\{g_{i-j\times t}+a_{t,j}\} fi​=0≤j≤szt​max​{gi−j×t​+at,j​}

这个式子可以看作是一个类多重背包，于是考虑使用多重背包的分组优化方法。

具体的，将所有的下标按  mod t\bmod tmodt 分组。设同组内的两个数为 i,ji,ji,j ，那么此时很显然背包的最优转移应该是同组内之间进行转移。

写出转移式子：

fi=max⁡0≤j≤ijmodt=imodt{gj+at,i−jt}f_i=\max_{\substack{{0\le j \le i}\\{j\bmod t=i\bmod t}}}\{g_j+a_{t,\frac{i-j}{t}}\} fi​=0≤j≤ijmodt=imodt​max​{gj​+at,ti−j​​}

注意到 i−jt\frac{i-j}{t}ti−j​ 总是整数，所以我们得出结论： aaa 具有凸性（或者凹性，反正差不多），同时注意到求解 fff 的式子实际上是一个 max-plus 卷积。由某一个定理得， fif_ifi​ 的转移具有决策单调性。所以对着优化就行。

时间复杂度 O(kmax⁡wlog⁡k+nlog⁡n)\mathcal{O}(k\max_w\log k+n\log n)O(kmaxw​logk+nlogn) 。
