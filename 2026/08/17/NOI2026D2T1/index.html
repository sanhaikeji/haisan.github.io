[NOI 2026] 中位数

我声称摩卡串是简单好写好想题。

题目链接： [NOI 2026] 中位数 。

题目描述：

把长度为 nnn 的序列切成 kkk 段，要求每段中位数构成的序列的中位数最大。

5≤n≤106,2≤k≤n5\le n \le 10^6,2\le k \le n5≤n≤106,2≤k≤n 。

中位数的定义：长度为 mmm 的序列的中位数为第 ⌈m2⌉\lceil\frac{m}{2}\rceil⌈2m​⌉ 大的数。

警示后人：

性质 A\text{A}A ， k mod 2≡0k\bmod 2\equiv 0kmod2≡0 和 k>5k>5k>5 是诈骗性质。

这个题目就是让你冲正解的，几乎没有部分分。

经典二分转 1,−11,-11,−1 序列 bbb 。

那么一个序列的中位数 ≥x\ge x≥x 的充要条件为序列的和 ≥0\ge 0≥0 。

现在问题变成了：判定一个 −1,1-1,1−1,1 的序列 bbb 是否能切成 kkk 份使得至少有 ⌈k2⌉\lceil\frac{k}{2}\rceil⌈2k​⌉ 个子区间的和 ≥0\ge 0≥0 。

首先，我们有一个显然的构造：选取 ⌈k2⌉\lceil\frac{k}{2}\rceil⌈2k​⌉ 个 111 单独成一个子区间，然后序列就会断成 k+(k mod 2)+1k+(k\bmod 2)+1k+(kmod2)+1 个区间。

接着我们就要根据 k mod 2k\bmod 2kmod2 分类讨论：

Case #1 : k mod 2=0k\bmod 2=0kmod2=0

此时我们需要删除一个区间。

考虑什么情况下我们可以删除区间。

由于序列能断成 k+(k mod 2)+1k+(k\bmod 2)+1k+(kmod2)+1 个区间的时候，他的样子应该是：

01010101010101010⋯010101010101010101010101001010101010101010\cdots0101010101010101010101010 01010101010101010⋯0101010101010101010101010

那么我们就有三种方式删除区间：

  1. 让开头变为 111 ，即 10101010⋯010101010\textcolor{red}{1}0101010\cdots01010101010101010⋯010101010 。
  2. 让结尾变为 111 ，即 010101010⋯01010101010101010\cdots0101010\textcolor{red}{1}010101010⋯01010101 。
  3. 让中间两个 111 相邻，即 0101010⋯0101011010101⋯01010100101010\cdots01010\textcolor{red}{11}010101\cdots01010100101010⋯0101011010101⋯0101010 。

接下来考虑如何处理这三种情况。

首先第一第二种是容易的，只需要枚举一个前后缀，然后判断剩余区间的 111 的个数是否合法就行。

然后就是第三种。这种情况下我们可以枚举一个 iii ，预处理出 posipos_iposi​ 表示最大的满足 [posi,i][pos_i,i][posi​,i] 的和 ≥0\ge 0≥0 的数， pos2ipos2_ipos2i​ 表示最小的满足 [i,pos2i][i,pos2_i][i,pos2i​] 的和 ≥0\ge 0≥0 的数。用 posipos_iposi​ 和 pos2i+1pos2_{i+1}pos2i+1​ 转移就行。

问题是如何线性预处理 pos,pos2pos,pos2pos,pos2 。

以 pospospos 举例。

理论上，我们为了处理这个，需要整一个值域数组，每次单点修改，以及查询一个后缀的最大值。这似乎只能 O(log⁡n)O(\log n)O(logn) 做。但是，这是一个 −1,1-1,1−1,1 序列。这也就意味着，对于某一个 iii ，若 bi=1b_i=1bi​=1 ，则 posi=ipos_i=iposi​=i ，否则必然有 [posi,i][pos_i,i][posi​,i] 的和为 000 。此时就是一个单点修改，单点查询，一个桶搞定。

Case #2 : k mod 2=1k\bmod 2=1kmod2=1

此时要删两个区间。

那么，将 Case #1 的三种删除区间的方法组合以下，可以得到以下七种：

  1. 两端都是 111 ，即 101010⋯01010101\textcolor{red}{1}01010\cdots0101010\textcolor{red}{1}101010⋯01010101 。
  2. 开头的连续两个 111 ，即 1101010⋯010101010\textcolor{red}{11}01010\cdots0101010101101010⋯010101010 。
  3. 结尾的连续两个 111 ，即 010101010⋯0101011010101010\cdots01010\textcolor{red}{11}010101010⋯0101011 。
  4. 开头一个 111 ，中间连续两个 111 ，即 10101010⋯0101011010101⋯0101010\textcolor{red}{1}0101010\cdots01010\textcolor{red}{11}010101\cdots010101010101010⋯0101011010101⋯0101010 。
  5. 结尾一个 111 ，中间连续两个 111 ，即 0101010⋯0101011010101⋯010101010101010\cdots01010\textcolor{red}{11}010101\cdots0101010\textcolor{red}{1}0101010⋯0101011010101⋯01010101 。
  6. 中间连续 333 个 111 ，即 0101010⋯01010111010101⋯01010100101010\cdots01010\textcolor{red}{111}010101\cdots01010100101010⋯01010111010101⋯0101010 。
  7. 两个无交的连续的两个 111 ，即 0101010⋯0101011010101⋯0101011010101⋯01010100101010\cdots01010\textcolor{red}{11}010101\cdots01010\textcolor{red}{11}010101\cdots01010100101010⋯0101011010101⋯0101011010101⋯0101010 。

前 555 种利用 pos,pos2pos,pos2pos,pos2 容易转移。

第 777 种利用一个辅助数组也可以轻松转移。

主要是第 666 种。

首先一个直观的想法是枚举 iii ，然后令三个区间分别为 [posposi−1,posi−1][posi,i][i+1,pos2i+1][pos_{pos_i-1},pos_i-1][pos_i,i][i+1,pos2_{i+1}][posposi​−1​,posi​−1][posi​,i][i+1,pos2i+1​] 。

然而这是错的。

举一个例子， 100101100101100101 ，有一个显然的划分为 (10)(01)(01)(10)(01)(01)(10)(01)(01) ，但是如果套用刚才的那个算法就会挂掉。这是因为最短的 ≥0\ge 0≥0 的区间的另一个端点不一定也有对应的 ≥0\ge 0≥0 的区间。换句话说，也就是，可能 posposi−1pos_{pos_i-1}posposi​−1​ 不存在但是存在一个更小的 qqq 满足 [posq−1,q−1][q,i][pos_{q-1},q-1][q,i][posq−1​,q−1][q,i] 合法。

解决它也十分简单。令 pip_ipi​ 为最大的满足 [p,i][p,i][p,i] 的和恰好为 000 的数。那么枚举 iii ，令三个区间先分别为 [posposi−1,posi−1][posi,i][i+1,pos2i+1][pos_{pos_i-1},pos_i-1][pos_i,i][i+1,pos2_{i+1}][posposi​−1​,posi​−1][posi​,i][i+1,pos2i+1​] ，再分别为 [pospi−1,pi−1][pi,i][i+1,pos2i+1][pos_{p_i-1},p_i-1][p_i,i][i+1,pos2_{i+1}][pospi​−1​,pi​−1][pi​,i][i+1,pos2i+1​] 。

原因十分简单，如果存在一个更小的 qqq 满足 q<piq<p_iq<pi​ 且 posq−1pos_{q-1}posq−1​ 存在且 pospi−1pos_{p_i-1}pospi​−1​ 不存在，不妨设 pi<posip_i<pos_ipi​<posi​ ，那么必然有 [q,i][q,i][q,i] 的和为 000 。又因为 [p,i][p,i][p,i] 的和也为 000 ，所以 [q,p−1][q,p-1][q,p−1] 的和为 000 ，也就是说， pip_ipi​ 必然存在且至少为 qqq ，矛盾，所以原假设不成立，考虑 posipos_iposi​ 和 pip_ipi​ 可以涵盖所有情况。

以上是整个题目最难的部分（不是就这？），大力出奇迹的分类讨论就行。
